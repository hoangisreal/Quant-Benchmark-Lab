# Experiment configuration

Shared defaults live in `runtime.yaml`, `generation.yaml` and `protocol.yaml`.
`models.yaml` is the source/model catalog; preparation resolves artifact hashes and
official templates. `experiments/` defines the three GPU matrices and a separate CPU
integration check. `demo.yaml` uses fixture data and synthetic backends.

Paths resolve relative to the YAML defining them. A binary name without `/` is resolved
on `PATH`; an explicit binary path and `toolchain_lock` resolve against the defining
runtime YAML, whether inline or included from another file.

`settings_audit.example.json` is unapproved. `settings_audit.json` records source review
for the candidate engines; its binary hashes must match the local build when pinning.
The source review cannot replace effective-context, cache, offload and GPU probes.

`frozen/` is generated by `qbl freeze` only after a passing preflight. Its configurations
contain absolute paths and are ignored. Keep them with their unchanged schedules and
certificates for local execution/resume. Raw campaigns snapshot the resolved configuration,
datasets and identities; preserve that entire directory when sharing evidence.

Do not change shared settings, datasets or binaries between preflight and official runs.
See [methodology](../docs/reference/methodology.md) and [campaign workflow](../docs/guides/reproduction.md).
